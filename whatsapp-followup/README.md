# 📱 WhatsApp Smart Follow-up & Campaign System

সম্পূর্ণ স্বয়ংক্রিয় WhatsApp ফলো-আপ, জেমিনি এআই ইন্টিগ্রেশন, অ্যান্টি-ব্যান প্রোটেকশন এবং অফার ক্যাম্পেইন প্যানেল।

---

## 🚀 কীভাবে চালাবেন? (How to Run)

১. টার্মিনাল বা PowerShell খুলে এই ফোল্ডারে যান:
```bash
cd "e:\partition 3\tlegram auto mation\whatsapp-followup"
```

২. সার্ভার চালু করুন:
```bash
npm start
```
বা সরাসরি:
```bash
node src/index.js
```

৩. ব্রাউজারে ড্যাশবোর্ড ওপেন করুন:
👉 **http://localhost:3006**

৪. ড্যাশবোর্ডে প্রদর্শিত **WhatsApp QR কোডটি** আপনার ফোনের WhatsApp দিয়ে স্ক্যান করুন (`Linked Devices -> Link a Device`)।
একবার স্ক্যান করলেই সেশন সেভ থাকবে—পরবর্তীতে আর স্ক্যান করতে হবে না।

## 📁 ফোল্ডার পরিচিতি

```
whatsapp-followup/
├── 📁 media/
│   ├── audio/          <- আপনার কণ্ঠের ভয়েস রেকর্ড (.mp3 / .ogg)
│   ├── images/         <- প্রোডাক্টের ফটো (.jpg / .png)
│   └── texts/          <- টেক্সট টেমপ্লেট ফাইল (.txt)
├── 📁 database/
│   └── data.db         <- SQLite ডেটাবেজ (রোলিং ৩০ দিন)
├── 📁 dashboard/
│   ├── index.html      <- ওয়েব ড্যাশবোর্ড
│   ├── style.css
│   └── app.js
├── 📁 sessions/        <- WhatsApp লগইন সেশন (QR সেভ থাকবে)
├── 📁 src/
│   ├── index.js        <- এক্সপ্রেস সার্ভার ও এপিআই
│   ├── whatsapp.js     <- Baileys কানেকশন
│   ├── followup.js     <- ৫-ধাপ ফলো-আপ লজিক
│   ├── campaign.js     <- অফার ক্যাম্পেইন প্যানেল
│   ├── gemini.js       <- এআই ইন্টিগ্রেশন ও মডেল সুইচিং
│   ├── antiban.js      <- হিউম্যান টাইপিং ও অ্যান্টি-ব্যান
│   └── scheduler.js    <- স্বয়ংক্রিয় ক্রন জব
└── config.json         <- কনফিগারেশন ফাইল
```
